# SynthPass

**Single-pass synthetic image generation for Unreal Engine.**

SynthPass renders Unreal CG directly against a live or recorded video source in one render pass, producing photorealistic frames that can be used as training data, simulation output, or real-time display output. Because the real-world plate and the synthetic geometry resolve in the same pass, the output is a single coherent frame — not a stack of layers merged after the fact.

The plugin is domain-agnostic. Anything you can model, animate, or import into Unreal can be placed into real footage and captured at scale.

## Why single-pass matters for datasets

Most synthetic data workflows render CG in isolation, then blend it onto a background in a separate step. That separation introduces lighting mismatch, edge artifacts, and an extra pipeline stage to maintain.

SynthPass resolves the source plate and the synthetic content together:

- Translucent materials — glass, liquids, smoke, plastics, medical films — resolve correctly against the real background instead of against black.
- Transparent-background output gives you a clean alpha matte for the synthetic content in the same run.
- Per-actor isolation lets you re-render the same frame with only one subject visible, which is how you generate segmentation targets and per-object crops.
- Output lands in a `UTextureRenderTarget2D`, so your capture, labelling, and export logic stays in your own code.

## Features

- Ingests a video source through `UMediaTexture` — file, capture card, webcam, or network stream — and renders Unreal CG against it.
- Single-pass, single-renderer output.
- Correct handling of translucent materials.
- Transparent background support for alpha-matte output.
- Independently adjustable weights for the synthetic layer and the virtual world layer, so you can vary synthetic prominence across a dataset.
- Per-actor isolation ("show only") for generating masks, crops, and single-subject variants of the same frame.
- Optional direct-to-viewport output for live preview.
- Fully Blueprint-callable API through an engine subsystem — dataset loops can be authored without touching C++.

## Installation

Clone or download this repository into your project's `Plugins` folder:

```bash
cd <YourProject>/Plugins
git clone https://github.com/Saish-in3d/SynthPass.git
```

Regenerate your project files (right-click the `.uproject` → **Generate Visual Studio project files**).

Build the project, then enable **GPUCompositionGraphicsPipeline** under **Edit → Plugins** if it isn't already.

## Quick start

The core of the plugin is the `UCompGraphicsSubsystem` engine subsystem, accessible from both C++ and Blueprints.

```cpp
// Grab the subsystem
UCompGraphicsSubsystem* SynthPass = GEngine->GetEngineSubsystem<UCompGraphicsSubsystem>();

// Configure the output (resolution, format, etc.)
FCompositorOutputSpecs Specs;
SynthPass->ConfigureCompositorOutput(Specs);

// Feed in the source footage
SynthPass->SetInputMediaTexture(MySourceTexture, /*TransparentMediaTexture=*/ false);

// Initialize and run
SynthPass->InitilizeCompositor();
SynthPass->StartCompositor();

// Read the generated frame
UTextureRenderTarget2D* Frame = SynthPass->GetCompositionOutputRenderTarget();
```

Typical lifecycle:

```
InitilizeCompositor()  ->  ConfigureCompositorOutput()  ->  SetInputMediaTexture()
        ->  StartCompositor()  ->  (read GetCompositionOutputRenderTarget)
        ->  EndCompositor()  ->  DeinitializeCompositor()
```

### Generating a labelled variant set

A common dataset pattern is to capture the full frame, then re-capture it with each subject isolated to produce mask targets:

```cpp
// Full frame
SynthPass->ResetShowOnlyActors();
UTextureRenderTarget2D* FullFrame = SynthPass->GetCompositionOutputRenderTarget();
// ... your export step here

// Per-subject isolation
for (AActor* Subject : Subjects)
{
    SynthPass->ResetShowOnlyActors();
    SynthPass->AddShowOnlyActor(Subject);

    UTextureRenderTarget2D* Isolated = SynthPass->GetCompositionOutputRenderTarget();
    // ... your export step here
}
```

Frame export, file naming, and annotation format are left to your project — SynthPass hands you the render target and stays out of your data schema.

## API reference — `UCompGraphicsSubsystem`

All functions are `BlueprintCallable` under the **GPU Composition** category unless noted otherwise.

### Lifecycle

| Function | Description |
|---|---|
| `void InitilizeCompositor()` | Initializes the pipeline and its internal resources. |
| `void StartCompositor()` | Starts frame generation. |
| `void EndCompositor()` | Stops frame generation. |
| `void DeinitializeCompositor()` | Tears down the pipeline and releases its resources. |
| `bool GetShouldCompositorRun()` | Returns whether the pipeline is currently set to run. |

### Input & output

| Function | Description |
|---|---|
| `void SetInputMediaTexture(UMediaTexture* inMediaTexture, bool TransparentMediaTexture)` | Sets the source video texture and whether it should be treated as transparent. |
| `void ConfigureCompositorOutput(FCompositorOutputSpecs inCompositorOutputSpecs)` | Configures the output specs (resolution, format, etc.). |
| `void SetCompositionResolution(float X, float Y)` | Sets the resolution of the generated frame. |
| `UTextureRenderTarget2D* GetCompositionOutputRenderTarget()` | Returns the render target containing the generated frame. |

### Layer weights

| Function | Description |
|---|---|
| `void SetCGOverlayonBackgroundFootageValue(float Value)` | Sets the weight of the synthetic CG drawn over the source footage. |
| `float GetCGOverlayonBackgroundFootageValue()` | Returns the current CG-over-footage weight. |
| `void SetVirtualWorldOverlayValue(float Value)` | Sets the weight of the virtual world layer. |
| `float GetVirtualWorldOverlayValue()` | Returns the current virtual world layer weight. |

Both weights default to `1.0`. Varying them across a run is a cheap way to add appearance diversity to a dataset.

### Actor isolation

Restrict which actors are rendered into the frame — used for isolating subjects, generating masks, and building per-object variants.

| Function | Description |
|---|---|
| `void SetShowOnlyActors(TArray<AActor*> inActorsArray)` | Replaces the show-only set with the supplied array of actors. |
| `void AddShowOnlyActor(AActor* inActor)` | Adds a single actor to the show-only set. |
| `void RemoveShowOnlyActor(AActor* inActor)` | Removes a single actor from the show-only set. |
| `void ResetShowOnlyActors()` | Clears the show-only set. |

### Viewport output

| Function | Description |
|---|---|
| `void ToggleCompOutputOnViewport(bool inShallCompOutputOnViewport)` | Enables or disables drawing the generated frame to the viewport. |
| `bool GetShallCompOutputOnViewport()` | Returns whether the generated frame is drawn to the viewport. |
